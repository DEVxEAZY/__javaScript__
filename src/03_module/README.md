# Módulo 03 — qualidade e ferramentas no dia a dia

Material de apoio às aulas que começam **depois** do núcleo Node/Express do `02_module`. A ordem do curso importa: primeiro o editor igual para todos, depois ESLint.

| Ordem | Pasta / arquivo | Tema |
|-------|-----------------|------|
| 1 | [`editorconfig/`](editorconfig/) — [`EDITORCONFIG.md`](editorconfig/EDITORCONFIG.md) + [`.editorconfig`](.editorconfig) | Indent 2, LF, UTF-8 — Windows/Linux iguais |
| 2 | [`eslint/`](eslint/) — [`ESLINT.md`](eslint/ESLINT.md) | ESLint, guia Airbnb ([`GUIA_AIRBNB.md`](eslint/GUIA_AIRBNB.md)), auto-fix |
| 3 | [`API/`](API/) — [`API_REST.MD`](API/API_REST.MD) | API REST Express + **Prisma** (SQLite local; opcional MySQL como na aula) |

Pré-requisitos: Node.js 18+ (a partir do lab ESLint) e editor com extensões recomendadas em cada pasta.
